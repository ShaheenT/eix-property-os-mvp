# EiX Property OS — Property Score™ Beta

A production-oriented Next.js beta for the EiX Property Score™ experience.

Included: premium responsive landing page, property assessment flow, transparent 0–100 weighted scoring, five score dimensions, optional indicative rental-yield calculation, results/report view, agency positioning and Vercel-ready configuration.

## Run
npm install
npm run dev

## Production
npm run build
npm start

Import the repository into Vercel. The current standalone beta requires no environment variables.

## Beta disclaimer
The score is an indicative prototype using user-entered inputs. It is not a formal valuation, financial advice, credit decision, or investment guarantee.
